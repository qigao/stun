================================================================================
  HOW TO USE DDF EXAMPLES WITH modern_whiteboard.exe
================================================================================

GOOD NEWS: The Import DDF button has been added! ✅

The DDF (Diagram Definition Format) system is fully implemented and you can
now load the example JSON files directly from the application UI!

================================================================================
  WHAT ARE THESE FILES?
================================================================================

This directory contains example DDF documents:

  - org_chart.json        : Organization chart with hierarchical layout
  - network_diagram.json  : Network topology with force-directed layout
  - flowchart.json        : Process flowchart with orthogonal connectors

These are JSON files that define diagrams using the DDF format.

================================================================================
  HOW CAN I USE THEM?
================================================================================

Option 1: USE THE IMPORT BUTTON (Recommended) ✅
-------------------------------------------------
The easiest way - use the built-in Import DDF button!

1. Build the application:
     cd build
     cmake --build . --config Release --target modern_whiteboard

2. Launch the application:
     cd build\Release
     modern_whiteboard.exe

3. Click File menu → Import DDF

4. Browse to whiteboard\examples\ddf\

5. Select an example file (org_chart.json, network_diagram.json, flowchart.json)

6. Click Open - the diagram loads automatically!


Option 2: VIEW THE JSON
------------------------
Open the files in a text editor to see the DDF format structure:

  notepad flowchart.json

This shows you how DDF documents are structured.


Option 3: PROGRAMMATIC LOADING
-------------------------------
If you're a developer, modify the application code to load examples:

  // In ModernWhiteboardApp or CanvasView initialization
  #include "whiteboard/ddf/ddf_document.h"
  
  auto ddf_doc = std::make_shared<whiteboard::ddf::DDFDocument>();
  if (ddf_doc->load_from_file("../../whiteboard/examples/ddf/flowchart.json")) {
      // Document loaded successfully
  }

Then rebuild:
  cd build
  cmake --build . --config Release


Option 4: RUN TESTS
-------------------
The examples are tested in the unit test suite:

  cd build\Release
  ctest -R ddf -V

This verifies the examples load and render correctly.
