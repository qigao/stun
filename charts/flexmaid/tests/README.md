# FlexMaid Testing & Comparison Framework

This directory contains comprehensive testing tools for FlexMaid, including visual comparison with the official Mermaid.js library.

## 📁 Directory Structure

```
tests/
├── scripts/
│   ├── generate_reference_svgs.py   # Generate reference SVGs using official Mermaid
│   └── generate_html_report.py      # Create visual comparison HTML report
├── fixtures/                         # Test .mmd files organized by diagram type
├── reference_output/                 # SVGs generated by official Mermaid.js
├── flexmaid_output/                  # SVGs generated by FlexMaid
├── comparison_report.json            # JSON comparison data
└── comparison_report.html            # Interactive visual comparison
```

## 🚀 Quick Start

### Prerequisites

1. **Install official Mermaid CLI**:
   ```bash
   npm install -g @mermaid-js/mermaid-cli
   ```

2. **Install Python dependencies** (optional, for comparison scripts):
   ```bash
   pip install pyppeteer
   ```

3. **Build FlexMaid**:
   ```bash
   cd build/Ninja/Msvc
   ninja flexmaid
   ```

### Running Tests

#### 1. Run Fixture Tests
```bash
cd build/Ninja/Msvc/bin
./flexmaid_fixture_tests.exe
```

This runs all 30 fixture tests and reports:
- ✅ Pass/Fail status
- ⏱️ Parse time for each diagram
- 📊 Summary statistics

#### 2. Generate Reference SVGs
```bash
cd charts/flexmaid/tests/scripts
python generate_reference_svgs.py
```

This will:
- Process all `.mmd` files in `fixtures/`
- Generate SVGs using official Mermaid.js → `reference_output/`
- Generate SVGs using FlexMaid → `flexmaid_output/`
- Create `comparison_report.json` with metrics

#### 3. Generate Visual Comparison Report
```bash
python generate_html_report.py
```

This creates an interactive HTML report (`comparison_report.html`) with:
- 📊 Side-by-side SVG comparisons
- 🔍 Search and filter capabilities
- ⚡ Performance metrics
- 📈 Success rate statistics

Open `comparison_report.html` in your browser to view!

## 🔧 Advanced Usage

### Custom Test Fixtures

Add new test files to `fixtures/<diagram_type>/`:
```
fixtures/
└── flowchart/
    ├── basic.mmd
    ├── custom_test.mmd  ← Add your test here
    └── ...
```

Then re-run the fixture tests.

### Debugging Failed Tests

1. Check the error message in test output
2. View the `.mmd` file in `fixtures/`
3. Run FlexMaid manually:
   ```bash
   ./flexmaid_example.exe path/to/test.mmd output.svg
   ```
4. Compare with reference:
   ```bash
   mmdc -i path/to/test.mmd -o reference.svg
   ```

### Performance Profiling

Use the comparison report to identify slow diagrams:
```python
# In generate_reference_svgs.py results
for file in results["files"]:
    if file["flexmaid"]["time_ms"] > 1.0:  # Slower than 1ms
        print(f"Slow: {file['path']} - {file['flexmaid']['time_ms']:.2f}ms")
```
