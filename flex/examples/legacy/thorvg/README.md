# Retired ThorVG example hosts

These source files and their paired `.flex` assets are preserved only as
migration references. They target the removed ThorVG software renderer and are
intentionally excluded from the Flex example build.

New and maintained examples belong in `flex/examples/` and must use one of the
supported OpenGL, Vulkan, TUI, or Direct2D backends. Do not add this directory
to CMake; migrate an example to a supported backend before re-enabling it.
